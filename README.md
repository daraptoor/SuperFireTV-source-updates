# SuperFire TV

A native media player for Android phones, tablets, Android TV and Android-based Fire TV.

**[Download latest APK](https://github.com/daraptoor/SuperFireTV-source-updates/releases/latest)** · [Release history](https://github.com/daraptoor/SuperFireTV-source-updates/releases) · [Support](https://github.com/daraptoor/SuperFireTV-source-updates/issues)

## Features

- Live TV, movie and series browsing
- Favorites, Continue Watching and supported offline downloads
- Touch and TV remote controls
- Liquid Glass interface on phones and tablets

## Install & update

Download the **.apk** from the latest release and open it on your device. Requires **Android 6.0+** or **Android-based Fire OS 6+**.

For future updates, use **Settings → App update**.
